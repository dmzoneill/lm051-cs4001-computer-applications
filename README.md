Java coursework for the CS4001 Computer Applications module, from the LM051
Computer Systems degree at the University of Limerick.

## What it does

A console program that lets you pick a text file, then edit it: remove a chosen
line, or find and replace text. It reports errors such as a file that cannot be
read or written, or missing input.

## Tech

- Java (Eclipse project)

## Running

Import the project into Eclipse, or compile and run the classes in `src` with
`javac` and `java`.
